# gaze-model — project page

A single-page, paper-style writeup of the kHz 2-D gaze reconstruction work,
in the ML/robotics project-page idiom: Source Serif 4 / Inter type system,
MathJax equations, and figures generated by `make_figures.py`.

```
docs/
├── index.html        the article
├── style.css         standalone type system (no framework)
├── make_figures.py   regenerates figures/fig_*.png from results/ numbers
├── figures/          fig_system, fig_alias, fig_ratesweep, fig_methods
└── .nojekyll         serve assets verbatim (no Jekyll)
```

## Preview locally

```bash
python3 -m http.server 8000 --directory docs
# open http://localhost:8000
```

## Regenerate figures

```bash
python3 docs/make_figures.py
```

The two data figures (`fig_ratesweep`, `fig_methods`) are re-rendered from the
numbers in `results/rate_sweep_verdict.md` and `results/khz2d_methods.md`; the
two schematics (`fig_system`, `fig_alias`) are conceptual and labelled as such.

## Publish on GitHub Pages

Repo Settings → Pages → **Deploy from a branch** → branch `main`, folder
**`/docs`**. The page serves at `https://<user>.github.io/gaze-model/`.

## Notes

- Framed as a preprint; numbers come from `results/*.md`. Verify the reference
  list against primary sources before any submission.
- The page loads Google Fonts and MathJax from CDNs; vendor them into `docs/`
  if a fully offline page is needed.
- Result videos (`results/animations/*.mp4`) are git-ignored for size; the
  Video section references their repo paths.
